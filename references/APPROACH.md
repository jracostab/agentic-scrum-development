# Approach (why this shape)

You already run the SDLC by hand with one Hermes co-founder and this implementer. The pack freezes that into roles, gates, and GitHub as the backlog so a Developer agent can be assigned a story without inventing process.

Turn-key in two days means: labels + agent text + `workitems.sh` + comment language. Not a new orchestrator, not a Hermes rewrite, not moving CEO/CTO off Claude Code yet.

Later: same verbs on another tracker; Hermes profiles for CTO/Developer; Action or cron that pings the Developer when `status:ready-for-dev` is set.
