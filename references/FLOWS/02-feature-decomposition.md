# Flow 2 — Feature backlog + story split

Actors: Founder (A), Product Owner + tech-lead (CTO, DE, or PE) (R), Developer (C on DoD).

1. Founder: “Decompose epic #N.”
2. PO states outcome; tech-lead (CTO, DE, or PE) proposes features (still chat or a gist).
3. Founder `approved`.
4. PO/tech-lead create `type:feature` issues, `Parent: #N`.
5. For the next sprint candidate, the tech-lead splits one feature into `type:story` issues:
   - Description (user-facing)
   - DoD (testable)
   - notes on files if known
6. Stories stay Todo. Not assigned to Developer until Flow 3.

Do not write code in this flow.
