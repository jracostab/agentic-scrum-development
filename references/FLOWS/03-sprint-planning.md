# Flow 3 — Sprint planning

Actors: Founder (A), Product Owner (R), tech-lead (CTO, DE, or PE) (R).

1. Founder: “Plan sprint 2026-w39” (or current week).
2. PO + tech-lead list ready stories (DoD present, parent feature open).
3. They propose a sprint set that fits ~one Developer agent + your review time (start with 1–3 stories).
4. Gate G2: Founder `sprint yes`.
5. Label those issues `sprint:2026-w39`. Create a tracking issue:

```
Title: Sprint 2026-w39
Labels: type:epic (or a sprint label)
Body: list of story numbers + goal
```

6. PO comments on each story: `Sprint 2026-w39 committed.`

Start of sprint ≠ start of coding. Coding is Flow 4 after G3.
