# Flow 1 — Product backlog

Actors: Founder (A), Co-Founder PO (R), CEO (C).

1. Founder: “Define the product / refresh the backlog for venture X.”
2. PO reads AGENTS.md, venture FOUNDING.md, existing `type:epic` issues.
3. PO drafts 3–7 epics in chat (EXAMPLES/issue-bodies.md). No GitHub yet.
4. Gate G1: Founder edits + `approved`.
5. PO creates issues: `type:epic`, Description + DoD. Comment `Parent: none`.
6. CEO may comment alignment; does not create or close epics.

Stop. Do not split features until Founder asks.
